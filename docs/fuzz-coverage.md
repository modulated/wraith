# What the execution-checked fuzzer covers

Generated by `tests/fuzz_exec.rs`; do not edit by hand. Regenerate with:

```text
WRAITH_BLESS_FUZZ_COVERAGE=1 cargo test --test fuzz_exec coverage
```

Every construct in the language's AST is listed. **Programs** is how many of 400 generated programs contain it, counted by parsing the emitted source and walking the real AST — so the scaffolding each program needs is counted too, not just the part the generator models. Where a construct is generated, the note says what is *not* varied within it; where it is not generated, the note says why, because "not covered" should be a decision on the record rather than an omission.

The variant lists are read from `src/ast/*.rs` at test time, so a construct added to the language shows up here as uncovered rather than going unmentioned.
